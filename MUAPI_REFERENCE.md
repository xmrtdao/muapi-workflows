## MUAPI Platform Features

### Workflow Builder (Visual)
- Multi-node execution graphs
- Jinja2 template syntax for node references
- AI Agentic Architect for natural language workflow creation
- REST API: POST /api/workflow/{workflow_id}/run
- CLI: muapi workflow create "description" --view

### Agents
- Intelligent personas with custom skills and memory
- Design Agent API for visual design
- Agent Skills: pre-built capabilities mapped to models

### Storyboarding
- Character and scene consistency across content
- Ideal for episodic/long-form content

### Integration Options
- REST API, Python SDK, JS SDK
- ComfyUI nodes (11 dedicated nodes)
- n8n community nodes (60+ models, drag-and-drop)
- MCP Server (for AI coding assistants)
- CLI (muapi workflow discover/get/run/create)

### Webhooks
- Async result notification on workflow completion
- Per-node granular updates

### File Upload
