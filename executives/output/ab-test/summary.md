# A/B Test: nano-banana-pro vs flux-dev-image for Marketing

## Result: nano-banana-pro wins for text-based marketing materials

### nano-banana-pro ($0.12/image)
- ✅ Renders readable, correctly-spelled text
- ✅ Good for: logos, banners, ads, dashboards, UI mockups, social media graphics
- ✅ Professional quality output
- ⏱ ~40s generation time

### flux-dev-image ($0.015/image)
- ❌ Text renders as gibberish/gobbledygook
- ✅ Good for: backgrounds, favicons, textures, scenes, abstract art, patterns
- ✅ 8x cheaper than nano-banana-pro
- ⏱ ~7s generation time

## Recommendation
| Use Case | Model | Cost |
|----------|-------|------|
| Marketing materials with text | nano-banana-pro | $0.12 |
| Logos, banners, ads | nano-banana-pro | $0.12 |
| UI mockups, dashboards | nano-banana-pro | $0.12 |
| Backgrounds, textures | flux-dev-image | $0.015 |
| Favicons, patterns | flux-dev-image | $0.015 |
| Scene art, abstract | flux-dev-image | $0.015 |
